# Changelog

## 0.2.0

- Added persistent asset and data-source registries, validated `/api/v1` endpoints, searchable and paginated list/detail/create/edit screens, additive migration `0002`, OpenAPI documentation, and registry tests. Data-source connectors and ingestion remain unimplemented; write endpoints remain unauthenticated and loopback-only by default.

## Unreleased

- Established the portable TypeScript workspace, React/Vite frontend, Fastify API, shared health contract, PostgreSQL connection, versioned migration runner, and Docker Compose baseline.
- No industrial data features are implemented in this foundation.
